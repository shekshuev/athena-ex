## Что такое сигнал

**Сигнал** – это явно названное наблюдение об обучающемся, срабатывающее по фиксированному правилу: «прошёл блок слишком быстро», «низкий балл за задание», «ничего не открывал за период». У каждого сигнала есть значение, с которым он сработал, и база сравнения. Скрытых весов нет: статус обучающегося на экране :ui[Group Radar] определяется только количеством и видом сработавших сигналов (см. [Радар группы](/docs/engagement/group-radar)).

Сигналы делятся на категории. Название категории показывается в карточке обучающегося, а короткое название сигнала – в чипах колонки :ui[Why].

| Категория | Подпись | Откуда берётся |
|---|---|---|
| Активность | :ui[Activity] | Наличие событий за период |
| Честность | :ui[Integrity] | Поведение во время тестирования |
| Результаты | :ui[Results] | Баллы и попытки по оцениваемым заданиям |
| Прогресс | :ui[Progress] | Пройденные блоки курса |
| Поверхностное прохождение | :ui[Rushing] | Поведение на блоках |
| Трудности | :ui[Difficulties] | Поведение на блоках |

## Сравнение с группой

Многие сигналы сравнивают обучающегося не с фиксированным числом, а с его учебной группой по тому же блоку за тот же период. Используются две базы:

- **медиана времени на блоке**: для каждого обучающегося, у которого на блоке есть визиты, берётся его среднее время; медиана этих значений и есть «обычное время группы»;
- **80-й перцентиль смен ответа**: для каждого обучающегося, у которого на блоке есть события, берётся число смен ответа; 80-й перцентиль – значение, которое не превышают 80% группы.

База считается, только если данные есть **не меньше чем у 5 обучающихся** (`min_group_for_baseline`). При меньшем числе сравнение с группой не делается, а действуют только фиксированные пороги. Так два-три человека не определяют, что «нормально».

Медиана и перцентиль используются вместо среднего, потому что распределения времени и смен ответа сильно скошены: один обучающийся, оставивший страницу открытой на час, не должен сдвигать «норму» всей группы.

## Сигналы поведения на блоках

Вычисляются для каждого обучающегося на каждом блоке, который он открывал за период.

### Поверхностное прохождение

| Сигнал | Чип | Правило |
|---|---|---|
| Слишком быстро | :ui[Too fast] | Если для блока задано ожидаемое время: среднее время обучающегося < 0,5 × ожидаемого. Иначе, при наличии базы группы: среднее время < 0,4 × медианы группы |
| Не дочитывает | :ui[Doesn't read to the end] | Текстовый блок: :ui[Scrolled, %] < 70 |
| Вставляет ответы | :ui[Pastes answers] | Вопрос или задача с кодом: :ui[Share pasted] > 0,8 |
| Перематывает видео | :ui[Skips video] | Видео: :ui[Share skipped] > 0,3 |
| Не запускает код | :ui[Doesn't run code] | Задача с кодом: код ни разу не запускался, и :ui[Share pasted] > 0,5 |

> [!NOTE]
> Порог «слишком быстро» для сигнала (0,5 ожидаемого времени) не совпадает с порогом быстрого прохождения для подсказки (по умолчанию 0,4). Это разные решения: сигнал для преподавателя и мгновенная подсказка обучающемуся.

### Трудности

| Сигнал | Чип | Правило |
|---|---|---|
| Очень долго | :ui[Very slow] | Если задано ожидаемое время: среднее время > 2 × ожидаемого. Иначе, при наличии базы группы: среднее время > 2,5 × медианы группы |
| Меняет ответы | :ui[Changes answers] | Не меньше 2 смен ответа и больше 80-го перцентиля группы. Без базы группы – не меньше 3 смен |
| Перезапускает код | :ui[Re-runs code] | Метрика :ui[Rapid re-runs] равна «Да» |

Возврат к уже пройденному материалу не считается сигналом обучающегося: он обычно говорит о самоконтроле, а не о проблеме. Возвраты учитываются только на уровне блока (см. ниже).

### Честность

Срабатывают только на блоках тестирования.

| Сигнал | Правило |
|---|---|
| Попытка снимка экрана | :ui[Screenshot attempts] > 0 |
| Попытка копирования | :ui[Copy attempts] > 0 |
| Попытка вырезать текст | :ui[Cut attempts] > 0 |
| Несколько вкладок | :ui[Opened in several tabs] > 0 |
| Частый уход со страницы | :ui[Left the exam tab] ≥ 3 |
| Вставка ответов | :ui[Share pasted] на тестировании > 0,6 |

Все сигналы этой категории в колонке :ui[Why] объединяются в один чип :ui[Exam violations].

Это упрощённые абсолютные правила для экранов вовлечённости. Индикатор риска конкретной попытки, по которому преподаватель принимает решение при проверке, считается иначе – с очками и сравнением с другими участниками того же тестирования (см. [Академическая честность](/docs/grading/academic-integrity)).

## Сигналы результатов

Учитываются оцениваемые задания, лучшая попытка по которым отправлена в пределах периода.

| Сигнал | Чип | Правило |
|---|---|---|
| Низкий балл | :ui[Low score] | Балл < 50, **и** медиана группы по заданию не ниже 50 (или базы группы нет). Либо балл ниже медианы группы на 30 и более |
| Много попыток | :ui[Many attempts] | При наличии базы группы: не меньше 3 попыток и не меньше 2 × медианы группы. Без базы: больше 3 попыток |

Медианы по заданию считаются, если оценки (или попытки) есть не меньше чем у 5 обучающихся.

Условие «медиана группы не ниже 50» означает: если задание проваливает большинство группы, это проблема задания, а не обучающегося. Такое задание видно на карте курса как проблемное место.

Сигнал :ui[Many attempts] дополнительно помечается как **неразрешённый**, если лучшая попытка так и осталась ниже 50 баллов. Многократные попытки, завершившиеся сдачей, – это настойчивость, и на статус они не влияют.

### Теория перед заданием

К сигналам результатов прикладывается сведение о том, как обучающийся прошёл **теорию перед заданием**. Явной связи «теория – задание» в курсе нет, поэтому она выводится по положению:

- теория задания – это неоцениваемые блоки (текст, видео, изображение, вложение), идущие в том же разделе между предыдущим оцениваемым блоком и этим заданием;
- если перед заданием в его разделе таких блоков нет (раздел начинается с задания), берутся все неоцениваемые блоки предыдущего раздела.

Каждый блок теории получает одну из трёх оценок, по всей истории курса (материал мог быть прочитан задолго до задания):

| Оценка | Условие |
|---|---|
| :ui[studied normally] | Блок открывался, и на нём не сработал ни один из сигналов :ui[Too fast], :ui[Doesn't read to the end], :ui[Skips video] |
| :ui[skimmed] | Блок открывался, но сработал хотя бы один из этих сигналов |
| :ui[never opened] | Событий на блоке нет |

## Сигналы прогресса

Прогресс – это факт по всему курсу, он не зависит от выбранного периода. Сигналы прогресса считаются, только если в учебной группе не меньше 5 обучающихся.

| Сигнал | Чип | Правило |
|---|---|---|
| Пропущенный блок | :ui[Skipped blocks] | Блок пройден не меньше чем 60% группы, но не пройден обучающимся. Срабатывает отдельно на каждый такой блок |
| Отставание | :ui[Behind the group] | Прогресс по курсу ниже медианы прогресса группы на 20 пунктов и более |

**Прогресс по курсу** – доля блоков курса, отмеченных как пройденные, в процентах. Для команды учитывается общий прогресс команды.

## Сигнал активности

| Сигнал | Чип | Правило |
|---|---|---|
| Нет активности | :ui[No activity] | У обучающегося нет ни одного события в курсе за период, а у кого-то из группы есть |

Если за период не занимался никто (например, каникулы), сигнал не срабатывает ни у кого.

## Сигналы блока

Эти правила описывают блок для учебной группы целиком, а не отдельного обучающегося. Они используются на карте курса.

| Сигнал | Правило |
|---|---|
| :ui[Students come back] | :ui[Share who came back] > 0,4 |
| :ui[Answers keep changing] | :ui[Share who changed answers] > 0,4 |

Остальные проблемные места карты курса описаны в разделе [Радар курса](/docs/engagement/course-radar).
