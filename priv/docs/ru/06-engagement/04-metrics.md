## Как устроен расчёт

События одного обучающегося на одном блоке за один календарный день сворачиваются в набор **счётчиков и сумм** (количество входов, сумма времени, количество вставок и так далее). Счётчики складываются без потерь: неделя обучающегося – это сумма его семи дней, показатель учебной группы по блоку – сумма показателей её обучающихся. Каждая метрика вычисляется из этих сумм по одной формуле, где бы она ни показывалась.

Метрики видны в детальном виде блока на экране :ui[Course Radar] (сетка значений над графиком :ui[Weekly trend]). В зависимости от объектива :ui[Looking at] значения относятся ко всей учебной группе или к одному обучающемуся. Детальный вид блока всегда считается за всю историю курса, а не за выбранный период.

Обозначения в формулах:

- *визит* – одна пара «вход блока в видимую область – выход из неё» в рамках одной сессии;
- *сессия* – одно открытие страницы плеера или тестирования;
- *наблюдаемые обучающиеся* – обучающиеся, у которых есть хотя бы одно событие на блоке.

Если метрику не из чего вычислить (например, нет ни одного визита), показывается «–».

## Общие метрики

Вычисляются для блоков любого типа.

| Метрика | Определение и формула |
|---|---|
| :ui[Visits measured] | Количество визитов |
| :ui[Average time, s] | Сумма времени всех визитов (за вычетом простоя) / количество визитов |
| :ui[Time vs. planned] | :ui[Average time, s] / ожидаемое время блока. Показывается, только если ожидаемое время задано |
| :ui[Students] | Количество наблюдаемых обучающихся |
| :ui[Tab switches] | Количество скрытий вкладки, пока блок был на экране |
| :ui[Time to first action, s] | Среднее по сессиям время от входа блока в видимую область до первого действия на нём |
| :ui[Share of time in other tabs] | Суммарное время со скрытой вкладкой / суммарное время на экране без вычета простоя; не больше 1 |
| :ui[Came back after moving on] | Количество возвратов: в одной сессии и в один день обучающийся вернулся к блоку, уже открыв более поздний блок того же раздела. На одного обучающегося в сессию засчитывается не больше одного возврата к блоку |
| :ui[Share who came back] | :ui[Came back after moving on] / количество наблюдаемых обучающихся |
| :ui[Share who changed answers] | Доля наблюдаемых обучающихся, хотя бы раз сменивших ответ |

## Метрики по типам блоков

### Текст

| Метрика | Определение и формула |
|---|---|
| :ui[Scrolled, %] | Среднее по сессиям значение максимальной отметки видимости (0, 25, 50, 75 или 100%). Подробнее об ограничении для длинных текстов – в разделе [Сбор данных](/docs/engagement/data-collection) |

### Видео

| Метрика | Определение и формула |
|---|---|
| :ui[Plays] | Количество запусков |
| :ui[Pauses] | Количество пауз |
| :ui[Rewinds] | Количество перемоток в любую сторону |
| :ui[Watched to the end] | Количество досмотров до конца |
| :ui[Share skipped] | Среднее по сессиям, в которых видео досмотрено до конца: сумма перемоток вперёд в секундах / длительность видео. Сессии без досмотра не учитываются, так как в них неизвестна длительность |

### Вопрос

| Метрика | Определение и формула |
|---|---|
| :ui[Share pasted] | Среднее по всем вставкам: вставлено символов / всего символов в ответе на момент вставки |
| :ui[Answer changes] | Количество смен ответа после первого выбора |

### Задача с кодом

| Метрика | Определение и формула |
|---|---|
| :ui[Share pasted] | Как для вопроса |
| :ui[Code runs] | Количество нажатий кнопки запуска кода |
| :ui[Ran the code] | «Да», если код запускался хотя бы раз |
| :ui[Rapid re-runs] | «Да», если не меньше трёх раз интервал между соседними запусками кода (в пределах одного дня) был меньше 10 секунд |

### Вложение

| Метрика | Определение и формула |
|---|---|
| :ui[Opens] | Количество открытий файла |
| :ui[Students who opened] | Количество обучающихся, открывших файл хотя бы раз |

### Изображение

| Метрика | Определение и формула |
|---|---|
| :ui[Zooms] | Количество увеличений изображения |

### Тестирование и тестирование по билетам

| Метрика | Определение и формула |
|---|---|
| :ui[Left the exam tab] | Количество скрытий вкладки во время попытки |
| :ui[Time away from the exam, s] | Суммарное время со скрытой вкладкой |
| :ui[Window lost focus] | Количество потерь фокуса окна |
| :ui[Screenshot attempts] | Количество нажатий PrintScreen |
| :ui[Copy attempts] | Количество попыток копирования текста вопроса |
| :ui[Cut attempts] | Количество попыток вырезать текст вопроса |
| :ui[Opened in several tabs] | Количество обнаружений той же попытки в другой вкладке |
| :ui[Idle time, s] | Суммарное время простоя |

## Показатели учебной группы

Когда метрика считается для учебной группы, счётчики и суммы всех её обучающихся складываются, а затем применяется та же формула. Поэтому, например, :ui[Average time, s] группы – это среднее по **всем визитам** всех обучающихся, а не среднее из средних по обучающимся. Обучающийся, заходивший на блок много раз, влияет на среднее сильнее.

Для сравнения обучающегося с группой используются другие величины – медиана и перцентиль по обучающимся, см. [Справочник сигналов](/docs/engagement/signals).
