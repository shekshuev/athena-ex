## Настройки вовлечённости

У каждого раздела и каждого блока курса есть три необязательных параметра. Они задаются в конструкторе курса, в блоке :ui[Engagement Tracking] инспектора:

1. Откройте :ui[Studio] › :ui[Course Manager] и перейдите в конструктор нужного курса.
2. Выберите раздел или блок. Справа откроется инспектор.
3. Заполните поля в блоке :ui[Engagement Tracking].

Блок :ui[Engagement Tracking] виден только пользователям с правом `engagement.update`.

| Поле | Значение | Где используется |
|---|---|---|
| :ui[Expected time to complete (seconds)] | Сколько секунд, по замыслу автора, требуется на блок | Сигналы :ui[Too fast] и :ui[Very slow]; метрика :ui[Time vs. planned]; запасное правило подсказки о быстром прохождении |
| :ui[Fast-completion threshold (0-1)] | Какая доля ожидаемого времени считается «слишком быстро» для подсказки | Только подсказка о быстром прохождении |
| :ui[Allow nudges in this section?] / :ui[Allow nudges on this block?] | Разрешены ли подсказки | Все подсказки |

### Наследование

Каждое поле определяется отдельно, по первому заданному значению в цепочке:

1. значение блока;
2. значение раздела, в котором лежит блок;
3. значение по умолчанию для приложения (см. [Справочник порогов](/docs/engagement/thresholds)).

Пустое поле и вариант :ui[Inherit] означают «взять значение уровнем выше». Для разрешения подсказок явный вариант :ui[Disabled] на уровне блока запрещает подсказки на этом блоке, даже если раздел их разрешает. Если подсказки не настроены нигде, они разрешены.

По умолчанию ожидаемое время не задано ни для одного блока, а порог быстрого прохождения равен 0,4.

> [!TIP]
> Ожидаемое время стоит задавать для блоков, где автор хорошо представляет нужный темп, например для коротких видео или заданий. Если ожидаемое время не задано, время на блоке сравнивается с медианой учебной группы, что для большинства блоков точнее.

## Подсказки обучающимся

Подсказка – короткое всплывающее сообщение в плеере курса, которое обучающийся видит, когда проходит материал заметно поверхностнее обычного. Подсказка не блокирует прохождение и не влияет на оценку.

### Условия показа

Подсказка показывается, только если одновременно:

- подсказки включены для учебной группы обучающегося;
- подсказки разрешены для блока (с учётом наследования);
- в текущей сессии подсказка с той же причиной на этом блоке ещё не показывалась.

> [!WARNING]
> Включение подсказок для учебной группы в текущей версии не вынесено в интерфейс: по умолчанию они выключены у всех учебных групп и команд. Включить их может администратор системы.

### Причины подсказок

| Причина | Условие | Текст, который видит обучающийся |
|---|---|---|
| Быстрое прохождение | См. ниже | «:ui[You went through that pretty fast - want to go back and double-check?]» |
| Текст не дочитан | Текстовый блок покинут, а максимальная видимая доля его высоты меньше 70% | «:ui[Looks like you scrolled past without reading much - want to go back?]» |
| Вставлен готовый ответ | Одна вставка составила больше 80% символов ответа (вопрос с открытым ответом или задача с кодом) | «:ui[Looks like you pasted a ready-made answer - are you sure you understand it?]» |
| Видео перемотано | Видео досмотрено до конца, но перемотка вперёд в сумме превысила 30% его длительности | «:ui[You skipped through most of that video - sure you got it all?]» |

Если на выходе из текстового блока сработала подсказка «Текст не дочитан», подсказка о быстром прохождении на этом блоке уже не показывается.

### Быстрое прохождение

Решение принимается в момент, когда блок уходит с экрана, по времени последнего просмотра блока:

1. Если по этому блоку в учебной группе накоплено **не меньше 15 измерений** времени, время просмотра сравнивается с распределением группы. Подсказка показывается, если оно попадает в **нижние 10%** распределения.
2. Если измерений меньше, но для блока задано ожидаемое время, подсказка показывается при времени меньше `ожидаемое время × порог быстрого прохождения`. Например, при ожидаемом времени 300 с и пороге 0,4 – меньше 120 с.
3. Если нет ни достаточной выборки, ни ожидаемого времени, подсказка не показывается.

Распределение времени по блоку можно увидеть в детальном виде блока на экране :ui[Course Radar] (график :ui[Dwell distribution]; нижние 10% выделены красным).

> [!NOTE]
> Для этого решения используется время просмотра без вычета простоя, поскольку решение принимается сразу, до обработки событий простоя.

### Как оценить пользу подсказок

На экране :ui[Course Radar] на вкладке :ui[Activity] график :ui[Nudge correction rate] показывает для каждой причины, какая доля подсказок не повторилась: после подсказки тот же сигнал у того же обучающегося больше не срабатывал ни на одном блоке курса. Подробнее – в разделе [Радар курса](/docs/engagement/course-radar).
