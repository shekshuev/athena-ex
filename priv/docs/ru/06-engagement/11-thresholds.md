## Где задаются

Пороги модуля задаются в конфигурации приложения, в секции `config :athena, Athena.Engagement` файла `config/config.exs`. Изменение порога требует перезапуска приложения и применяется ко всем курсам и учебным группам. Из интерфейса пороги не меняются; для отдельных разделов и блоков настраиваются только ожидаемое время, порог быстрого прохождения и разрешение подсказок (см. [Настройки и подсказки](/docs/engagement/settings-nudges)).

Доли записываются числами от 0 до 1, проценты – числами от 0 до 100.

## Настройки блоков по умолчанию

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `default_expected_seconds` | не задано | Ожидаемое время блока, если оно не задано ни у блока, ни у раздела |
| `default_fast_ratio_threshold` | 0,4 | Порог быстрого прохождения для подсказки |

## Подсказки

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `min_sample_size_for_percentile` | 15 | Сколько измерений времени по блоку в группе нужно, чтобы решение о подсказке принималось по распределению группы |
| `min_scroll_percent_for_text` | 70 | Видимая доля текстового блока (%), ниже которой показывается подсказка и срабатывает сигнал :ui[Doesn't read to the end] |
| `paste_ratio_nudge_threshold` | 0,8 | Доля вставленного текста, выше которой показывается подсказка и срабатывает сигнал :ui[Pastes answers] |
| `video_skip_ratio_threshold` | 0,3 | Доля перемотанного видео, выше которой показывается подсказка и срабатывает сигнал :ui[Skips video] |

Граница «нижних 10%» распределения для подсказки о быстром прохождении фиксирована и не настраивается.

## Сигналы поведения

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `min_group_for_baseline` | 5 | Минимум обучающихся с данными, начиная с которого делается сравнение с группой (медианы, перцентили) |
| `concern_dwell_ratio_threshold` | 0,5 | :ui[Too fast] при заданном ожидаемом времени: время < порог × ожидаемое |
| `slow_dwell_ratio_threshold` | 2,0 | :ui[Very slow] при заданном ожидаемом времени: время > порог × ожидаемое |
| `group_fast_dwell_ratio` | 0,4 | :ui[Too fast] без ожидаемого времени: время < порог × медиана группы |
| `group_slow_dwell_ratio` | 2,5 | :ui[Very slow] без ожидаемого времени: время > порог × медиана группы |
| `hesitation_min_changes` | 2 | Минимум смен ответа для :ui[Changes answers] |
| `hesitation_group_percentile` | 0,8 | Перцентиль группы, который нужно превысить для :ui[Changes answers] |
| `hesitation_absolute_changes` | 3 | Порог :ui[Changes answers] без базы группы |
| `panic_debug_gap_seconds` | 10 | Интервал между запусками кода, считающийся «быстрым» |
| `panic_debug_min_bursts` | 3 | Сколько быстрых интервалов нужно для :ui[Re-runs code] |
| `no_debug_paste_ratio` | 0,5 | Доля вставленного кода, начиная с которой незапущенное решение даёт :ui[Doesn't run code] |
| `concern_backtrack_rate_threshold` | 0,4 | :ui[Students come back] на карте курса |
| `concern_hesitation_rate_threshold` | 0,4 | :ui[Answers keep changing] на карте курса |
| `exam_focus_loss_threshold` | 3 | Число уходов со страницы тестирования для сигнала частого ухода |
| `exam_paste_ratio_threshold` | 0,6 | Доля вставленного текста на тестировании для сигнала вставки ответов |

## Результаты и прогресс

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `low_score_threshold` | 50 | Проходной балл для всех правил модуля |
| `low_score_group_gap` | 30 | На сколько баллов ниже медианы группы балл считается низким независимо от проходного |
| `many_attempts_min` | 3 | Минимум попыток для :ui[Many attempts] |
| `many_attempts_group_factor` | 2 | Во сколько раз число попыток должно превышать медиану группы |
| `not_mastering_min_low_scores` | 2 | Сколько низких баллов дают статус :ui[Not mastering the material] |
| `behind_progress_gap` | 20 | Отставание от медианы прогресса группы (пункты) для :ui[Behind the group] |
| `missed_block_group_share` | 0,6 | Доля группы, прошедшей блок, при которой блок считается «пройденным большинством» |
| `missed_blocks_for_behind` | 5 | Минимум пропущенных блоков для статуса :ui[Falling behind] |
| `missed_blocks_share` | 0,1 | Минимальная доля пропущенных среди блоков, пройденных большинством |

## Закономерности и статусы

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `pattern_min_blocks` | 3 | Минимум блоков с сигналами для статусов :ui[Skimming] и :ui[Struggling] |
| `pattern_block_share` | 0,25 | Минимальная доля таких блоков среди открытых |
| `pattern_group_factor` | 2 | Во сколько раз доля должна превышать медиану группы |
| `student_radar_integrity_threshold` | 1 | Сколько сигналов :ui[Integrity] дают статус :ui[Integrity risk] |
| `student_radar_default_window_days` | 7 | Период экранов по умолчанию, в днях |

## Карта курса

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `map_min_students` | 3 | Сколько обучающихся должно стоять за числом, чтобы блок стал проблемным |
| `map_low_pass_share` | 0,6 | Доля сдавших, ниже которой поднимается :ui[Low scores] |
| `map_critical_pass_share` | 0,4 | Доля сдавших, ниже которой :ui[Low scores] критична |
| `map_attempts_avg` | 2,5 | Среднее число попыток для :ui[Many attempts] на карте |
| `map_behaviour_share` | 0,4 | Доля открывших с сигналами для :ui[Rushed through] и :ui[Students get stuck] |

## Обработка и отображение

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `dashboard_cache_ttl_ms` | 60 000 | Время хранения рассчитанного экрана, мс; 0 отключает кэш |
| `histogram_buckets` | 10 | Число столбцов гистограммы :ui[Dwell distribution] |
| `histogram_max_seconds` | 1200 | Верхняя граница гистограммы, с |
| `block_stats_idle_timeout_minutes` | 30 | Через сколько минут без событий выгружается из памяти статистика блока для подсказок |

Частота фоновой задачи предварительного подсчёта задаётся переменной окружения `ENGAGEMENT_ROLLUP_CRON` (по умолчанию каждые 5 минут).

## Академическая честность

Пороги с префиксом `exam_` (кроме двух, перечисленных в разделе «Сигналы поведения») управляют индикатором риска попыток тестирования. Они описаны в разделе [Академическая честность](/docs/grading/academic-integrity).

## Устаревшие ключи

Ключи `student_radar_slacking_threshold` и `student_radar_struggling_threshold` относятся к прежней цветовой схеме радара и на текущие статусы не влияют.
